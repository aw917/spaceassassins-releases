# Space Assassins — downloads

Free multiplayer arena FPS for Windows, macOS and Linux (including Linux Mint), with a cartoon look,
CS:GO controls and peer-to-peer voice chat. Works across different networks with no port
forwarding, or fully offline on a LAN.

**[Download the latest version](https://github.com/aw917/spaceassassins-releases/releases/latest)**

| Your computer | File to download |
|---|---|
| Windows | `SpaceAssassins-…-Setup.exe` (installs and updates itself), or `…-Portable.exe` (no install) |
| macOS | `SpaceAssassins-…-mac-universal.dmg` |
| Linux Mint / Ubuntu / Debian | `SpaceAssassins-…-linux-amd64.deb` (updates itself) |
| Other Linux | `SpaceAssassins-…-linux-x86_64.AppImage` (updates itself) |

**macOS:** the app isn't notarised by Apple. The first time you open it, go to *System Settings →
Privacy & Security* and click **Open Anyway**.

**Play with friends:** open the game, choose **PLAY WITH FRIENDS**, and share the room code or invite
link. Whoever has the best computer becomes the host automatically.

This repository only holds the installers and the invite page. Installed apps check here for
updates.
